Mentor decks

Generate profile decks after the mentor deadline closes. Review each deck before it becomes visible to mentees. If you regenerate a deck, its approval resets, and it needs a new review. Approving a cohort's decks for the first time also opens that cohort's application window below. The two mentee cohorts are independent. Approving one does not affect the other.

Import edited decks

If a deck has a mistake, download it above. Fix it in PowerPoint or Keynote. Select the corrected file below to replace it.

Each file name must exactly match the name of the deck you downloaded. The system matches files by name only. If a file does not match an existing deck, the system skips it. New decks come only from the Generate mentor decks button above. Importing a deck resets its approval, the same as regenerating it.
